# 语境实验室精读模式设计与实施基线

> 状态：实施基线 v1.0
>
> 日期：2026-08-04
>
> 适用范围：学习端语境实验室的阅读任务；不新建训练流程、领域聚合或独立工作区。
>
> 证据边界：本文冻结交互、状态、接口和验收标准。实现通过自动化测试只能证明链路与约束成立，不证明句法识别绝对正确或真人学习效果。

## 1. 目标与既有功能归属

精读模式是现有用户旅程的扩展点：

`阅读原文 → 选中原文 → 仍没看懂 → 临时任务 → 返回主任务`

它不建立平行阅读器，不复制主任务状态机，也不改变阅读任务的完成门、提示等级、作答版本、证据快照或训练进度。新增能力只改变两个既有扩展点：

1. “仍没看懂”由普通不确定标注入口升级为整句精读入口；
2. 临时任务增加一种“整句精读”任务内容，仍由既有临时任务 Tab 承载。

用户退出精读后回到原文章、原滚动位置和原主任务；再次进入同一精读任务时恢复该任务的翻译、成分标记、显示配置和已解锁分析。

## 2. 核心教学顺序

精读模式必须执行以下顺序，不允许通过折叠区、预取结果或默认展开绕过：

1. 系统把选区归一为一个完整句子；
2. 右侧切到临时任务，用户可以在右侧写整句翻译，同时在左侧自主标记成分；
3. 翻译与成分标记互不锁定、不规定先后，任一侧的修改不清空另一侧；
4. 只有非空翻译和至少一处自主成分标记同时存在时，才允许点击“查看识别内容”；
5. 系统才请求或展示相关的语法、固定/常用搭配、熟词生义及候选成分识别；
6. 用户可继续修改自己的翻译或成分标记，也可退出后再次进入。

系统分析是对用户尝试的核对材料，不是进入精读模式时自动铺满句子的标准答案。

## 3. 整句归一规则

### 3.1 输入

输入沿用现有同段落 `TextSelection`：

- `paragraphId`；
- 段落内 `start` / `end` 字符偏移；
- `textQuote`。

### 3.2 句界

英文句界由 `.?!` 及其紧随的右引号、右括号构成；句末没有标点时，段尾是最后一个句界。句首和句尾空白不属于精读句子范围。

### 3.3 选中不完整句时的决策

浏览器计算选区与段内每个句子区间的交集长度，选择交集字符数最大的句子。若相同：

1. 优先包含选区中心点的句子；
2. 仍相同则选文中更靠前的句子。

如果句界解析失败，回退为当前段落去除首尾空白后的完整文本，并明确标记为段落回退，不伪称已精确分句。

该归一函数必须是无 DOM 依赖的纯函数，并有边界、引号、跨句选区和并列最大交集测试。

## 4. 工作区与转场

### 4.1 左栏形态

普通形态继续展示完整文章。进入精读时，左栏转场为单句精读台：

- 顶部显示“整句精读”和原文段落位置；
- 中部只展示归一后的完整句子；
- 保留“返回全文”动作；
- 已经创建的精读任务提供“重新进入精读”动作；
- 退出后保留文章原滚动位置、定位结果和字号设置。

### 4.2 动画

转场采用同一阅读表面的共享视觉连续性，不使用全屏闪白或先卸载再空白等待：

1. `exit`（160–200ms）：全文降低透明度并轻微向后缩放，选中句保持强调；
2. `shared sentence`（220–320ms）：句子从原位置平移并放大到精读台主位置；
3. `enter`（180–240ms）：精读工具与阶段提示依次淡入。

返回全文使用反向动画。`prefers-reduced-motion` 或用户“减少动态效果”开启时，取消位移和缩放，仅做不超过 100ms 的透明度切换，并保持焦点正确迁移。

动画只改变 `transform` 和 `opacity`，避免逐帧修改布局属性。句子与工具使用稳定容器高度，防止右栏和分栏拖拽器抖动。

## 5. 右栏临时任务

选择“仍没看懂”后必须：

- 复用既有 `TemporaryTaskItem` 清单；
- 以句子来源键去重：`intensive-reading:{taskId}:{paragraphId}:{start}:{end}`；
- 自动切换右侧为“临时任务” Tab；
- 展开对应精读任务；
- 不修改主任务版本、完成门或 `highest_hint_level`。

临时任务分三阶段：

| 阶段 | 右栏内容 | 左栏能力 |
|---|---|---|
| `attempt` | 翻译输入、标记计数与“查看识别内容” | 成分范围选择与翻译同时可用 |
| `analyzing` | 核对进度 | 暂停修改，避免请求中的快照漂移 |
| `review` | 精简保留用户翻译和非空相关内容 | 翻译与成分仍可修改，修改后回到 `attempt` |

翻译只要求非空，不自动判分；不设置单独的“提交翻译”门。精读临时任务不重复展示左侧已经可见的整句原文和“回到左侧”按钮，任务提示也不再使用独立大色块，以减少卡片占用。精读任务的“完成”表示用户完成一次翻译和自主标记/核对动作，不代表已经掌握该句。

“临时任务”Tab 本身就是该功能的容器，Tab 内不再建立第二层页面：不重复标题、关闭、汇总卡和返回页脚，也不使用 `modal` 视觉语义。内容层只保留新增动作、无边框空状态或任务项列表，用户通过顶部 Tab 切换回主任务。去除结构层级不得删除当前皮肤的角色插画、装饰资产或主题特征；这些元素应直接融入空状态内容层，不依赖外层卡片。

## 6. 句子成分自主标记

### 6.1 可标记成分

v1 提供以下成分，按需使用，不要求每句全部出现：

- 主语；
- 谓语；
- 宾语；
- 表语；
- 定语；
- 状语；
- 补语；
- 同位语；
- 从句连接词。

用户在精读句中选择一个非空范围，再选择成分类型。标记保存句内字符偏移、原文片段、类型和创建顺序。范围与原文不一致时拒绝保存。

同一范围重新选择成分时替换旧类型。与已有用户成分标记发生部分重叠时先提示替换，不静默叠加。系统候选识别和用户标记分层展示，系统结果不能覆盖用户标记。

### 6.2 默认视觉语法

| 成分 | 默认样式 |
|---|---|
| 主语 | 单下划线 |
| 谓语 | 波浪线 |
| 宾语 | 双横线 |
| 表语 | 点线 |
| 定语 | 浅色底纹 |
| 状语 | 虚线 |
| 补语 | 细框 |
| 同位语 | 括线 |
| 从句连接词 | 强调色底纹 |

样式不是语义本身；每个标记必须同时具备文字图例、`aria-label` 和可读的成分名。

### 6.3 可配置与冲突

每个成分可在精读台的“标记显示设置”弹窗中选择：

- 单下划线；
- 双横线；
- 波浪线；
- 点线；
- 虚线；
- 浅色底纹；
- 强调色底纹；
- 细框；
- 括线；
- 不显示线型。

样式选择必须复用偏好设置的统一 `Select` 控件、键盘行为和主题 token，不在精读弹窗里单独使用浏览器原生下拉框。

同一时刻一种非空样式只归属一个成分。若用户把主语改为宾语当前使用的“双横线”，界面必须显示：

`双横线当前用于宾语。替换后，宾语将改为“不显示线型”。`

只有用户确认后才执行原子替换；取消则保持原配置。不能在后台静默交换或让两个成分共享同一样式。

配置在当前阅读任务内保留，退出全文后再次进入仍生效。v1 不把显示偏好写成学习证据。

## 7. 识别内容与相关性门

### 7.1 请求时机

只有同时满足以下条件才调用既有选区分析能力：

- 用户已写下非空整句翻译；
- 用户已至少保存一处自主成分标记；
- 精读句子的段落 ID、偏移和原文已通过现有内容版本校验。

请求继续进入现有 `POST /tasks/{task_id}/annotations/analyze`，通过新增的可选精读上下文扩展，不创建第二套分析 API：

```json
{
  "analysis_mode": "intensive_reading",
  "learner_translation": "用户自己的整句翻译",
  "learner_component_marks": [
    {"role": "subject", "start": 0, "end": 12, "text_quote": "..."}
  ]
}
```

普通选区分析不传这些字段，行为保持不变。

### 7.2 结构化响应扩展

既有 `AnnotationAnalysisView` 增加可为空数组的字段：

- `sentence_components`：相关候选成分及句内偏移；
- `grammar_points`：本句实际出现、能定位到原文的语法；
- `collocations`：本句实际出现的固定或常用搭配；
- `familiar_word_senses`：本句中确有语境证据的熟词生义。

每一项必须带原文锚点或明确的原文短语。找不到可靠锚点时不返回该项。

### 7.3 禁止凑项

展示层按非空数组渲染卡片：

- 没有相关语法点，不显示“语法识别”空卡；
- 没有固定/常用搭配，不显示“搭配”卡；
- 没有熟词生义，不显示“熟词生义”卡；
- 四类都为空时，只显示“本句暂未识别出足够可靠的补充项”，并保留用户翻译和标记。

四类都为空时同时提供“查看降级原因”折叠区，展示结果来源、公开 `reason_code`、`boundary_note` 及本句候选项未展示的校验边界。不展示隐藏思维链，也不把确定性降级写成模型故障。

模型或确定性降级不得为了满足栏目数量而虚构搭配、词义或句法成分。低置信结果使用“候选”措辞，不能写成标准答案。

## 8. 状态、退出与重入

精读会话状态：

```text
inactive
  → entering
  → attempt
  → analyzing
  → review
  → exited
  → attempt | review（重入恢复）
```

关键约束：

- `exited` 只切回全文，不删除临时任务或精读状态；
- 重复点击同一句“仍没看懂”聚焦已有任务，不新增重复项；
- 选择另一句创建另一项临时任务，上一项仍可重入；
- 主任务暂停、右栏 Tab 切换和返回全文不清空当前页面中的精读状态；
- 切换到学习资产、画像或偏好等学习功能导航后，返回当前训练必须恢复同一任务和内容版本下的临时任务、翻译、标记、显示设置和分析结果；
- 内容版本变化后不把旧句子偏移套用到新材料；
- 分析失败保留用户翻译与标记，允许重试；
- 精读任务完成不自动提交主任务答案。

v1 沿用现有本地恢复模块，以任务 ID 和内容版本为边界将临时任务状态保存在当前浏览器会话；它只用于 SPA 学习功能导航切换和意外卸载恢复，不写成服务端学习证据，不新增平行服务端状态机。跨设备同步和跨会话长期保存仍属于后续统一临时任务持久化范围。

## 9. 可访问性与键盘

- 进入精读后焦点移动到精读句标题，读屏播报“已进入整句精读”；
- 返回全文后焦点回到原句所在段落；
- 成分类型和样式设置全部可用键盘操作；
- 线型之外始终有文字图例，颜色不作为唯一信息；
- 冲突替换使用可聚焦确认区并带 `role="alertdialog"` 语义；
- 动画期间不把焦点放到已隐藏节点；
- 精读句选择支持鼠标和键盘 Selection。

## 10. 实施切片

### 10.1 前端领域纯函数

- 句子区间解析和最大交集归一；
- 成分标记区间验证与分段渲染；
- 样式唯一占用和原子冲突替换；
- 精读阶段派生，不用 Effect 复制派生状态。

### 10.2 工作区集成

- “仍没看懂”启动或聚焦精读临时任务；
- `ReadingPane` 在全文与精读台之间切换；
- 右栏切到现有临时任务 Tab；
- 翻译、标记、分析失败和结果都保留在对应临时任务中。

### 10.3 API 扩展

- 在既有分析请求/响应上增加可选精读字段；
- 服务端重新验证用户成分标记的偏移和原文；
- 模型输出执行锚点、空数组、长度和置信边界校验；
- 普通选区分析保持向后兼容。

## 11. 验收标准

### 11.1 句子与转场

- 选中完整句、半句或跨两个句子的范围，均进入最大覆盖的完整句；
- 进入后左侧只显示该完整句，返回全文恢复原位置；
- 同一句可退出、重入且状态不丢；
- 减少动态效果时没有位移/缩放动画。

### 11.2 教学门控

- 翻译和成分标记可以任意先后或交替进行；
- 仅完成其中一项时不请求识别；
- 未主动点击“查看识别内容”前不展示系统语法、搭配、熟词生义和候选成分；
- 分析结果只展示非空且有原文依据的栏目。

### 11.3 标记与配置

- 用户能标主语、谓语、宾语及其余六类成分；
- 默认线型符合第 6.2 节；
- 修改为已占用样式时出现替换提示；
- 确认后新成分获得样式，原占用成分变为“不显示线型”；
- 取消后双方配置不变；
- 用户标记与系统候选分层，不发生静默覆盖。

### 11.4 既有链路回归

- 精读任务出现在现有临时任务 Tab，主任务版本与完成门不变；
- 普通生词、语法重点和好表达标注仍使用原流程；
- 选区分析、主任务作答、暂停恢复、随时记和表达实验室测试继续通过；
- API 对未携带精读字段的旧客户端响应兼容。

## 12. 明确不在 v1 范围

- 自动替用户提交翻译或自动判整句翻译分数；
- 进入精读即自动标满所有成分；
- 强制每句出现语法、搭配和熟词生义三类内容；
- 把临时精读完成计作主任务完成或能力掌握；
- 为精读单独建立服务端任务聚合、证据表或跨设备同步；
- 编辑或删除既有正式标注事实。
